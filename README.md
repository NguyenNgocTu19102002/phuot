# Techvina - Electronics Manufacturing Services

Website giới thiệu công ty sản xuất điện tử Techvina. 
Cung cấp thông tin về công ty, năng lực sản xuất (SMT, Box-build), dự án tiêu biểu và cơ hội nghề nghiệp.

## Công nghệ sử dụng
- Next.js 16 (App Router)
- React 19
- Tailwind CSS / Vanilla CSS Modules
- TypeScript

## Khởi động máy chủ phát triển
\`\`\`bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
\`\`\`
Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt để xem kết quả.
